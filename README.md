# Sims Legacy Studio

Локальный редактор семейных деревьев для The Sims 4. Скачайте `SimsLegacyStudio.exe` из [GitHub Releases](https://github.com/Lisichkinoff/SimsLegacyStudio/releases/latest) и запустите его в Windows 10 или 11 из папки, в которую у вас есть право записи. При первом запуске откроется демонстрационная семья. Пустое дерево создаётся в разделе **Мои династии → Новая династия**.

- Щёлкните по симу и откройте **Связи**. Выберите тип связи, найдите нужную карточку по имени или создайте новую. Для братьев и сестёр можно указать связь напрямую. Статус «Бывший партнёр» отмечается разбитым сердцем на древе и отображается в карточках обоих симов.
- В разделе **Древо животных** можно вручную добавить карточки питомцев, указать их родственников и связать их с хозяевами. Нажмите на маленький портрет рядом с симом, чтобы открыть питомца на его древе.
- В **Оформлении** доступны три вида портретов, палитра фона, своё фоновое изображение, цвет линий, сетка и подписи.
- Изменения сохраняются в `%LOCALAPPDATA%\SimsLegacyStudio\library.json`. Для переноса на другой компьютер сохраните файл `.simslegacy` через **Экспорт**. Файлы других игроков открываются в разделе **Мои династии**. Дерево также можно сохранить как PNG.

## Импорт из сохранения

1. Сохраните игру в The Sims 4. В редакторе нажмите **Из игры** и выберите `Slot_*.save` из папки `Документы\Electronic Arts\The Sims 4\saves`.
2. Выберите семью и укажите, нужны ли её родственники из других семей.
3. Отметьте нужных симов. Редактор перенесёт имена, возрастные стадии, распознанные черты характера и семейные связи в новую или открытую династию.

Редактор читает сохранение локально. Портреты можно добавить в карточках симов. Для предка, чьё имя отсутствует в данных дерева, отображается «Неизвестный предок».

## Автоимпорт симов

По умолчанию автоимпорт выключен. В **Настройках** отметьте **Автоматически добавлять новых симов** и сохраните настройку. Выберите основной файл `Slot_*.save`, семью в игре и династию в приложении. Если хотите следить также за родственниками из других семей, включите соответствующий флажок. При использовании «Сохранить как» на новый слот выберите новый файл в настройках.

Открытое приложение проверяет выбранный файл после сохранения игры. Для нового сима заполняются имя, возрастная стадия, известные черты, название пользовательской карьеры и статус смерти, если эти данные прочитаны из сохранения. Появляются также распознанные родственные связи с новыми симами. Остальные сведения и фотографии можно добавить вручную. Правки существующих карточек сохраняются, а отключение автоимпорта оставляет добавленные карточки в династии.

## Тема приложения

Переключите светлую или тёмную тему в **Настройки → Тема приложения**. Выбранная тема сохраняется после перезапуска. Цвет и фоновое изображение конкретной династии можно настроить отдельно в разделе **Оформление**.

## Импорт MCCC

В приложении нажмите **Импорт → Отчёты MCCC и GEDCOM**, выберите один или несколько файлов и отметьте нужных симов перед импортом.

1. Для имени и черт сима в игре откройте **MC Command Center → Sim Commands → Logging Commands → Log Sim Details**. Включите **Traits** и нажмите **Create Detail Log**. Созданный `MCCC_SimDetails_*.log` находится в папке мода. [Пример создания отчёта](https://www.patreon.com/egwarhammer/posts/mcccs-sim-detail-23680640)
2. Для списка симов на текущем участке откройте консоль игры и введите `get_pop s m lot`. Импортируйте созданный отчёт `MCCC_GetPop_*.log`. [Команда get_pop](https://deaderpool-mccc.com/mccomandcenter.html)
3. Для родственных связей установите модуль **MC Gedcom** и введите `gedcom Имя Фамилия` в консоли игры. Импортируйте созданный `.ged` из папки мода. [Документация MC Gedcom](https://deaderpool-mccc.com/mcgedcom.html)

## Сборка

В рабочей папке запустите `.\build.ps1` в PowerShell. Скрипт использует компилятор .NET Framework из Windows. Портреты и значок встраиваются в EXE.

## Обновления

Один раз откройте **Обновления → Доступ к GitHub** и создайте на GitHub fine-grained token для репозитория `Lisichkinoff/SimsLegacyStudio` с разрешением **Contents → Read-only**. Вставьте его в приложение и нажмите **Сохранить**. Windows шифрует ключ для текущего пользователя. Когда срок действия ключа истечёт, замените его в том же меню.

Приложение проверяет новую версию при запуске. Ручная проверка доступна в меню **Обновления**. После подтверждения приложение скачивает EXE, проверяет его версию и контрольную сумму SHA-256, сохраняет изменения и перезапускается. Библиотека династий хранится отдельно от EXE.

Чтобы выпустить новую версию, измените номер в `VERSION`, отправьте коммит в GitHub, затем отправьте соответствующий тег (например, `v1.2.1`). GitHub Actions соберёт EXE и опубликует его в приватном GitHub Release. Для уже загруженного тега сборку можно запустить вручную в **Actions → Publish Windows release**.

Портреты демонстрационной семьи находятся в `assets/portrait-0.jpg` — `assets/portrait-8.jpg`. Они созданы встроенным ImageGen по запросу на сетку 3 × 3 из девяти стилизованных 3D-портретов вымышленных персонажей в духе редактора The Sims, от детей до пожилых, с мягким светом и однотонными пастельными фонами.
